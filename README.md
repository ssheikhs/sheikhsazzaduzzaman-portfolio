# Sheikh Sazzaduzzaman — Portfolio

My personal portfolio: who I am, what I build, and how to reach me.

**Live site:** _add your Vercel link here_

## Sections

- Responsive navbar with links to every section and a mobile menu
- Hero with designation, photo, resume download and social links
- About me, skills (grouped by category), education and experience
- Projects with a details page for each one: tech stack, description, live link, GitHub repository, challenges and future plans
- Contact (email, phone, WhatsApp) and footer

## Tech stack

React 19, Vite, Tailwind CSS 4, React Router, React Icons. Hosted on Vercel.

## Run locally

```bash
npm install
npm run dev
```

Build for production with `npm run build`.

## Updating content

All text, links, skills and projects live in `src/data/portfolio.js`.
Images are in `public/images`, and the resume is `public/resume/Sheikh-Sazzaduzzaman-Resume.pdf`.
